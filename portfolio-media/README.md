# Media incluídos na exportação

`manus-storage/` contém cópias dos recursos remotos usados pelo conteúdo inicial do portefólio. `user-originals/` contém as fotografias de origem fornecidas para este projecto.

Durante a execução na plataforma Manus, o site continua a usar os caminhos duráveis `/manus-storage/...` configurados no conteúdo. Estas cópias são uma salvaguarda para transferência/arquivo; não alteram automaticamente esses URLs numa instalação local ou noutro fornecedor.
